### Installation

1. Download the zip for your platform from the release assets — `windows_x64`, `linux_x64`, `macos_arm64` or `macos_x64` (the `.whl` is the pip package for the `puree` CLI; Blender does not need it)
2. In Blender, go to Edit > Preferences > Get Extensions
3. Click the dropdown menu (⌄) > Install from Disk
4. Select the downloaded zip
5. Or, from a terminal: `pip install puree-ui` and `puree init` to start a project

Requires Blender 5.1 or newer.

> Find out what has changed in this version here: [full changelog](https://github.com/nicolaiprodromov/puree/compare/v{previous_version}...v{version}

## What's new in 0.2.0

| Feature | Summary |
|---|---|
| **Animated GIF** | `img: spinner.gif` — per-frame delays and loop count |
| **SVG** | `img: logo.svg` — rasterized in Rust at layout size, crisp on resize |
| **Video** | `video: clip.mp4` — `.mp4` `.webm` `.mkv` `.mov`; `autoplay` `loop` `muted` `volume` `playback_rate` `poster` `preload`; audio in sync |
| **Lottie** | `lottie: anim.json` — Bodymovin via rlottie, loops by default |
| **Video controls** | `controls: true` — play/pause, seek, time, mute, fullscreen; auto-hides; themable via `<video_id>_puree_vc_*` |
| **Fullscreen** | any container — `request_fullscreen()` / `exit_fullscreen()` / `.fullscreen` / `on_fullscreen_change`; `ESC` exits |
| **`container.media`** | `play` `pause` `toggle` `seek` `stop`; `current_time` `duration` `paused` `ended` `loop` `muted` `volume` `playback_rate` `ready_state`; `media.on("play" / "pause" / "ended" / "seeked" / "timeupdate" / "error" / "fullscreenchange")` |
| **Overlay pass** | `overlay: true` — draws a container subtree above images and video |
| **All platforms** | native core + full wheel set for windows-x64, linux-x64, macos-arm64, macos-x64; one zip per platform |

**Fixes**

- Component defaults (`components/defaults/*.scss`, `*.yaml`) now load — `markdown_defaults.scss` never applied before
- `focusable: true` containers receive focus on click
- Text-input update log lines moved from INFO to DEBUG

**Known limitations**

- `ESC` / `SPACE` require at least one text input in the UI (the fullscreen button always works)
- Controls-bar icons and labels switch instantly while the bar fades
- `playback_rate` other than `1.0` mutes audio
- SVG is static; Lottie takes Bodymovin `.json` only (no `.lottie`)
- Media nodes added while the UI is running need a UI restart

Docs: [Media Elements](https://github.com/nicolaiprodromov/puree/blob/master/docs/PUREE_SPEC.md#10-media-elements) · [`container.media`](https://github.com/nicolaiprodromov/puree/blob/master/docs/API.md#media-playback--containermedia) · [`[video_controls]`](https://github.com/nicolaiprodromov/puree/blob/master/docs/COMPONENTS.md#default-component-video_controls) · demo: `tests/helloworld` section 08
> [!WARNING]
> **Breaking change** — `img:` values now require the full filename with extension:
> `img: my_icon.png` instead of `img: my_icon`. Subfolders under `assets/` are
> supported (`img: icons/play.png`). Extensionless values render nothing and log
> a "did you mean" error in the Puree log.

> [!NOTE]
> Video (PyAV/FFmpeg) and Lottie (rlottie) decoders now **ship bundled** with Puree —
> `video:` / `lottie:` / animated media work out of the box
