### Installation

1. Download the archive file from the release assets
2. Edit the template files and design your user interface and functionality
3. In Blender, go to Edit > Preferences > Get Extensions
4. Click the dropdown menu (⌄) > Install from Disk
5. Select the downloaded archive file

> [!WARNING]
> **Breaking change** — `img:` values now require the full filename with extension:
> `img: my_icon.png` instead of `img: my_icon`. Subfolders under `assets/` are
> supported (`img: icons/play.png`). Extensionless values render nothing and log
> a "did you mean" error in the Puree log.

> [!IMPORTANT]
> Video (PyAV/FFmpeg) and Lottie (rlottie) decoders now **ship bundled** with Puree —
> `video:` / `lottie:` / animated media work out of the box, no per-addon wheels and no
> `puree init --with-video/--with-lottie` flags anymore. Size impact: +19–37 MB per
> platform (windows-x64 +27.9 MB, linux-x64 +36.6 MB, macos-arm64 +18.9 MB,
> macos-x64 +23.3 MB). A missing decoder still degrades gracefully (poster/blank + one
> warning) instead of crashing.
